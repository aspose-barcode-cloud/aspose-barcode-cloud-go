# Pdf417EncodeMode

PDF417 barcode encode mode. Mirrors https://reference.aspose.com/barcode/net/aspose.barcode.generation/pdf417encodemode/

## Allowable values
* **Pdf417EncodeModeAuto**
* Pdf417EncodeModeBinary
* Pdf417EncodeModeECI
* Pdf417EncodeModeExtended
